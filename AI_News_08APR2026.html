RightNow AI has released AutoKernel, an open-source framework leveraging an autonomous LLM agent loop to automate GPU kernel optimization for PyTorch models, addressing the scarcity of expertise and manual tuning challenges in maximizing GPU performance. The system, inspired by Andrej Karpathy’s autoresearch project, iteratively edits, benchmarks, and validates kernel code, utilizing a comprehensive 909-line instruction document to guide optimization across various tiers, from block size tuning to advanced algorithms. AutoKernel prioritizes optimization targets based on their impact on overall runtime using Amdahl’s law and incorporates a rigorous five-stage correctness harness to ensure reliability, supporting both Triton and CUDA C++ backends.

Kevin Gu's thirdlayer.inc has released AutoAgent, an open-source library that automates agent engineering by leveraging a "meta-agent" to autonomously iterate on an agent's harness—including system prompts, tools, and orchestration—without human intervention. Demonstrating its effectiveness, AutoAgent achieved top scores on both SpreadsheetBench (96.5%) and TerminalBench (55.1%) within 24 hours, surpassing human-engineered agents. This shift fundamentally alters the engineer's role from code creation to providing high-level directives, and the system's Harbor-compatible task format allows for broad applicability across diverse domains.
