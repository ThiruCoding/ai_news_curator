Stash is an open-source, persistent cognitive layer designed to provide AI agents with long-term memory, addressing a key limitation of current models like ChatGPT and Claude.ai which operate within closed platforms. Unlike Retrieval Augmented Generation (RAG), which relies on document searches, Stash learns from an agent's experiences—conversations, decisions, and failures—synthesizing them into a knowledge graph to build a deeper understanding of the user. Deployable via Docker Compose and compatible with the emerging Memory Connectivity Protocol (MCP), Stash aims to offer universal, vendor-neutral memory capabilities for custom agents and local LLMs, enabling continuous learning and eliminating repetitive explanations across sessions.
